## Portfolio Project:-
## End-to-End Vrinda Store Sales Analysis
Analyzed VRINDA STORE retail sales data to uncover customer behavior, sales trends, and order performance. Cleaned, transformed, and modeled data using Power BI and Power Query, and built interactive dashboards highlighting key KPIs such as sales, orders, category performance, and customer demographics. Delivered actionable insights to support data-driven business decisions.
### Technologies used:
Python,matplotlib,numpy,pandas, Jupyter Notebooks,EXCEL,POWER_BI.
### Project Workflow:
#### Data Collection:-
Download raw Vrinda_store data from Kaggle,The Vrinda Store dataset contains structured retail sales data, including customer details, orders, product categories, payment modes, and regional performance, used to analyze customer behavior, sales trends, and business performance.
#### Data Loading:-
Used Python in Jupyter Notebooks to clean, analyze, and explore the dataset, enabling effective data analysis and insight generation.
#### Data Cleaning and Transformation:-
Clean and preprocess the data using Pandas,Handle missing values and outliers,Normalize and transform data into analysis-ready formats.
#### Exploratory Data Analysis (EDA):-
Analyzed the Vrinda Store sales data in Jupyter Notebooks using Python, Matplotlib, and Seaborn to visualize sales trends, age-group behavior, order status distribution, and category-wise sales, along with statistical summaries to identify key patterns and insights.
